# 94.7 Waterside FM — Custom Radio Voices (.wav)

This folder contains the voice audio files (`.wav`) for **94.7 Waterside FM** radio hosts **DJ Gabriel** (male host) and **DJ Kpannah** (female host).

The game plays these `.wav` files directly using HTML5 Audio elements instead of relying on browser/internet TTS synthesizers.

---

## How to Use Your Own Voice Recordings

You can drop in or overwrite any `.wav` file in this folder with your own recorded voices!

### Audio Format Requirements
- **Format**: Standard PCM 16-bit `.wav`
- **Channels**: Mono (1 ch) or Stereo (2 ch)
- **Sample Rate**: 22,050 Hz or 44,100 Hz / 48,000 Hz
